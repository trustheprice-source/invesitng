# Module contracts — v0.1

These interfaces are shared across independently owned implementation tasks. Change them only with the coordinating agent.

## Dependencies and tests

Python 3.11+, numpy, pandas, scikit-learn. Optional LightGBM. Standard-library unittest, no pytest required. Package `ucg_lab` lives at repository root. Function inputs are copied, never mutated in place. Study environment identity records Python, NumPy, pandas, scikit-learn, SciPy, joblib, threadpoolctl, the project version and LightGBM; unavailable distributions are recorded explicitly as `not_installed`. Resume, freezing and holdout reject a changed environment before registering a new attempt or consuming the holdout. Recording an optional package state does not establish that its adapter was exercised.

## Canonical dataset

`manifest.json` contains `schema_version: 1`, `symbol: "UCG"`, `currency: "EUR"`, `timezone: "Europe/Rome"`, `data_kind: "synthetic"|"real"`, `bar_minutes: 1`, `timestamp_semantics: "interval_start"`, `price_basis: "raw"`, `volume_basis: "primary_continuous"`, `source`, `source_reference`, `acquired_at` (UTC ISO timestamp), `license_note`, `corporate_action_policy`, `bars_file`, `sessions_file`, optional `context_file`, optional `news_file`, and `provenance_verified` (false unless independently reviewed).

Paths resolve under the manifest directory only. Optional feeds are loaded only when their `context_file` or `news_file` manifest key is present; unreferenced CSVs are ignored. Bars CSV: `timestamp,open,high,low,close,volume`, optional **paired** `bid_open,ask_open` quote snapshots at that minute's start. Timestamps must include UTC offset; normalize to UTC. Values finite, positive prices, nonnegative volume; low <= open/close <= high, bid <= ask. One row per minute of the supplied continuous session, no duplicates or missing minutes. Zero-volume bars are allowed but do not establish fill availability. Quote execution requires quotes and positive volume at the execution bar.

Sessions CSV: `session_date,open,close`; unique sorted dates, UTC-aware timestamps, open < close, boundaries on whole minutes, local calendar date consistent with Europe/Rome. Bars are for interval [timestamp,timestamp+1 minute), within [session.open,session.close). No bars outside sessions. Opening/closing auctions are excluded from this initial trade universe. Real calendars must come from an authorized, verified source; synthetic demo calendars are invented weekday sessions.

Context CSV optional: `available_at,market_return_15m,sector_return_15m`; available_at UTC-aware and unique, chronological. Context features use the most recent row available by decision time, with max age 15 minutes; otherwise zero plus `context_available=0`.

News/event CSV optional: `event_id,published_at,available_at,event_type`; available_at >= published_at, UTC-aware. No text-model sentiment is included in v0.1. Deduplicate event IDs and count only available events in the last 60 minutes. Do not fabricate absent news as evidence no event existed.

`ucg_lab.data.Dataset` dataclass: `bars: DataFrame`, `sessions: DataFrame`, `manifest: dict`, `dataset_hash: str`, `audit: dict`, `context: DataFrame | None = None`, `news: DataFrame | None = None`.

`load_dataset(manifest_path: str | Path) -> Dataset` validates/normalizes, raising ValueError on invalid inputs. `audit_dataset(dataset: Dataset) -> dict` returns a JSON-safe report with `passed`, `errors`, `warnings`, `data_kind`, `dataset_hash`, `sessions`, `bars`, `first_session`, `last_session`, `quote_coverage`. Hash raw manifest and all referenced input bytes, including context/news.

## Causal features — task A

`build_features(dataset: Dataset, config: dict | None = None) -> DataFrame`. Config keys `bar_minutes` (must be 5), `volume_lookback_sessions` (default 20), `min_volume_history_sessions` (default 10), `context_max_age_minutes` (default 15). Aggregate only complete 5-minute buckets anchored to each session open. Index may be RangeIndex; columns are explicit.

Output: `decision_time` UTC (bucket end), `session_date` ISO string, `session_open`, `session_close`, `last_price`, `rvol`, `cumulative_rvol`, `rvol_ready` bool, `return_5m`, `return_15m`, `return_60m`, `vwap_distance`, `range_5m`, `volatility_30m`, `day_return`, `gap_return`, `opening_range_high`, `opening_range_low`, `opening_range_ready` bool, `market_return_15m`, `sector_return_15m`, `context_available`, `news_count_60m`, `news_available`.

Opening range is the first 30 minutes; it is unavailable before those minutes complete and never changes afterward. Return windows do not cross session boundaries except `gap_return` from previous session close. VWAP uses close*volume approximation, explicitly documented, through decision time only. Zero volume cannot divide by zero; rvol_ready=false until denominator/history valid. Historical baseline per bucket uses only earlier sessions, never current day/future. Same-clock cumulative denominator uses historical sums only through that bucket. All unavailable numerical features are NaN until model handling (market/news absence uses zero with availability flags). Export `FEATURE_COLUMNS` list excluding prices/timestamps/targets/opening_range_high/low and boolean readiness, including causal numerical return/volume/context/event features.

## Strategy and execution — task B

`generate_rule_signals(features: DataFrame, name: str, parameters: dict | None = None) -> DataFrame` returns `decision_time,score`, one per feature row, score 1.0/0.0. Names: `trend_pullback`, `opening_breakout`, `mean_reversion`. Require rvol_ready and opening range readiness where needed. Rules fixed by documented parameters, no tuning here.

`run_backtest(bars: DataFrame, sessions: DataFrame, signals: DataFrame, config: dict | None = None) -> BacktestResult`. Caller passes the evaluation-period bars/sessions/signals only. Config defaults: `initial_cash=10000.0`, `allocation_fraction=0.25`, `commission_rate=0.0005`, `minimum_commission=3.0`, `round_trip_spread_bps=10.0`, `slippage_bps_per_side=2.0`, `execution_mode="bar_proxy"`, `latency_minutes=1`, `holding_minutes=30`, `stop_loss_pct=0.01`, `daily_loss_limit_pct=0.02`, `score_threshold=0.0`, `cooldown_minutes=5`.

Signals qualify strictly when score > score_threshold. One entry per false-to-true signal episode. A true signal that persists does not re-arm until a later false signal. Ignore qualifying episodes while a position is open, do not queue a stale signal for later. An eligible entry first executes at a bar start >= decision_time + latency_minutes. Abort pending entry if a later false signal arrives first. No same-bar or same-close look-ahead. Do not open at or after the final minute; close remaining positions at the opening of the final minute of the session under a predetermined schedule.

Whole shares, no leverage; buy total notional+fee <= cash and entry notional <= allocation_fraction * current equity. Exit fixed minutes after entry, or stop earlier. A stop touched intrabar uses min(bar.open, stop_price) before sell friction; this is a bar approximation, not guaranteed risk protection. No profit target. End-of-session, time and gap-at-open exit actions precede any new entry on that bar; do not exit/re-enter in the same bar. Daily loss brake uses equity relative to start-of-session equity and blocks new entries; it is not a guaranteed loss ceiling. Signals reset by session.

`bar_proxy`: buy raw open*(1+(half round-trip spread+side slippage)/10000); sell raw open*(1-(half spread+side slippage)/10000). Stops use the stop/gap raw reference, not same-bar closing information. `quote_snapshot`: entry ask_open plus side slippage, time exit bid_open minus side slippage; no extra synthetic spread. Stops can only be approximated with OHLC; flag their execution proxy. Never fill when execution bar volume is zero; exit searches later valid bars, but if no closing opportunity remains raise ValueError rather than fabricate a flat account. Do not transfer positions overnight in this version.

`BacktestResult` dataclass has `trades: DataFrame`, `equity: DataFrame`, `events: list[dict]`. Trades fixed columns even when empty: `entry_time,exit_time,session_date,quantity,entry_price,exit_price,entry_fee,exit_fee,gross_pnl,net_pnl,net_return,exit_reason`. Equity one row per session (including zero-trade days): `session_date,equity,daily_return,net_pnl,trade_count`; first daily_return relative to initial_cash. Events JSON-safe and include timing, skips and risk brake reasons. Main simulator keeps cash/position state internally and ends each evaluated session flat. User-supplied `initial_cash` must remain strictly positive. A realized exact total loss is preserved as a -100% return; zero equity is absorbing across all later sessions and walk-forward folds, with zero subsequent P&L/trades and zero daily return by convention, without recapitalization. The orchestrator carries an exhausted account forward without issuing another positive-initial-capital simulator call or fitting new signals.

`build_forward_labels(features: DataFrame, bars: DataFrame, sessions: DataFrame, config: dict | None = None) -> DataFrame` returns `decision_time,target_return,label_end`, one per feature when an entry and fixed-time exit fit. Use same latency and fixed holding window, cost assumptions and initial allocation whole-share quantity; explicitly no stop in regression target. No trade spanning sessions. No guessed fill on zero volume. These future outcomes are targets ONLY, never features. Root merges labels with features by decision_time. Public helper `commission(notional: float, config: dict) -> float` may be provided.

## Numerical models and evidence — task C

`fit_predict_model(train: DataFrame, test: DataFrame, feature_columns: list[str], model_name: str="ridge", parameters: dict | None=None) -> np.ndarray`. train has `target_return,label_end,decision_time`; filter to nonnull outcomes with label_end strictly before earliest test decision. Fit imputation/scaling on train only; missing all-train columns use zero. Reject infinite values. Ridge alpha default 10.0. LightGBM optional import fails clearly if unavailable; no fallback. Require at least 30 valid training rows. Return finite one-score-per-test-row.

`walk_forward_splits(session_dates: list[str], train_sessions: int, test_sessions: int) -> list[tuple[list[str],list[str]]]`: chronological sorted unique dates required; rolling train window exactly train_sessions then contiguous test blocks including final shorter block; no overlap in test blocks.

`block_bootstrap_mean_ci(returns: np.ndarray | list[float], block_length: int=5, n_bootstrap: int=5000, alpha: float=0.05, seed: int=17) -> dict` with `mean,lower,upper,alpha,block_length,n_observations,n_bootstrap,method`. Circular contiguous blocks; reject nonfinite/empty invalid parameters. Estimates are approximate under dependence/stability assumptions.

`summarize_performance(equity: DataFrame, trades: DataFrame, config: dict | None=None) -> dict`: all daily returns including zeros, net return, annualized return (252-session convention, flag approximate), max drawdown including initial equity, worst_day, worst_week, win_rate, trades, active_day_fraction, active_week_fraction, longest_no_trade_sessions, mean_daily_return, mean_trade_net_return, profit_factor with JSON-safe None for undefined, total_fees, total_net_pnl, bootstrap_ci. Config `initial_cash`, `bootstrap_samples`, `block_length`, `alpha`, `family_size` (Bonferroni alpha/family_size), `seed`. Weekly return compounds daily returns within ISO year/week; weekly activity includes every represented week. Defaults 5000,5,0.05,12,17. State multiple-testing adjustment is approximate and bounded to the recorded family, not universal protection against adaptive searches.

`assess_evidence(metrics: dict, data_kind: str, phase: str, criteria: dict | None=None, provenance_verified: bool=False) -> dict`: statuses `SYNTHETIC_DEMO`, `RESEARCH_ONLY`, `HISTORICAL_CANDIDATE`, `PAPER_CANDIDATE`; all `eligible_for_live=False`. Synthetic always SYNTHETIC_DEMO. Default illustrative criteria `min_evaluation_sessions=60`, `min_trades=30`, `min_active_week_fraction=0.6`, `max_drawdown=0.1`, `min_mean_daily_return=0.0`. Candidate requires CI lower > min_mean_daily_return, net return >0, adequate sample/frequency, max_drawdown within bound, and real provenance_verified. `phase="holdout"` may return PAPER_CANDIDATE, never live qualification. Return failed_checks and caveats. These defaults are screening assumptions, not statistical laws or accepted personal risk limits.

`find_analogs(train: DataFrame, query: Series, feature_columns: list[str], max_cases: int=10) -> list[dict]`: only rows with decision_time and label_end strictly before query.decision_time; fit distance normalization on these rows; choose at most one case per session; include decision_time, distance,target_return,label_end,session_date as JSON-safe. Missing values impute training medians. Never filter for positive returns.

## Orchestration — root

Root owns JSON configuration validation, synthetic generation, SQLite trial/holdout/paper ledger, CLI, orchestration, HTML/JSON reporting, documentation and packaging. Task owners must not modify one another's files. Root writes `ucg_lab/__init__.py`, `__main__.py` and packaging only after test skeletons exist. Agent-owned tests may use `unittest`, `pandas`, `numpy` with their own small hand-built fixtures. Do not depend on demo generator implementation for financial expected values.


Root configuration requires JSON integers for integer-valued fields, including schema version, bar width, session counts, time windows, search/bootstrap counts, seed and minimum-sample criteria. Integral floats such as `1.0` and booleans are rejected. `stop_loss_pct` is strictly below 1; `daily_loss_limit_pct=1` remains allowed.

`StudyLedger(path, *, create=False)` opens an existing registry by default and requires the expected tables, columns and primary keys. Only initialization of a new study in an empty directory uses `create=True`, which exclusively creates a new file. All SQLite connections use `mode=rw`, so missing-file checks cannot silently create a replacement registry. Research resume, freeze, holdout, handoff, analog inspection and CLI status fail when an existing registry is missing or incompatible, without rewriting reports or frozen artifacts. Restore the original registry before continuing. This guards accidental file loss; it does not detect deliberate replacement with another valid-schema registry or provide tamper-proof storage.

`PaperBroker.submit(..., now=...)` and `PaperBroker.on_quote(..., now=...)` permit explicit receipt clocks only for `mode="simulation"`. Prospective mode uses the actual UTC receipt clock and rejects every non-None override before state changes. Rejection preserves orders, quotes and fills. Prospective paper mode still never authorizes live trading.
